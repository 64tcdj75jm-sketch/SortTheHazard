# Fix Now or Report?

A standalone hazard-sorting game for workplace safety awareness.

## Publish with GitHub Pages

1. Create a GitHub repository (or open the repository you want to use).
2. Upload `index.html`, `.nojekyll`, and `README.md` to the repository's **root** folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your publishing branch (usually `main`) and the `/ (root)` folder, then save.
6. Wait for GitHub Pages to finish deploying, then open the website URL shown in **Settings → Pages**.

The game is self-contained: the background image, CSS, and JavaScript are embedded in `index.html`; no build step or external libraries are required.
